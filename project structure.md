GYF Welfare Management System: Complete Project Blueprint1. Project Overview & Tech StackName: Gentil Ministry & Prayer Camp (GYF) Welfare Management System.  Architecture: Responsive Web Application / Progressive Web App (PWA) packaged for Android via Capacitor and Android Studio.  Frontend: HTML5, CSS3, Bootstrap 5 (hosted locally for security and offline stability), and JavaScript.Backend: PHP (using PDO for database operations).Database: MySQL.Color Scheme: Light white, light blue, and light yellow, featuring intuitive hover effects, smooth transitions, and clean typography.  Icons: Custom uploaded assets for both the PWA manifest icon and Android app icon.  2. Module SpecificationsA. Treasurer ModuleAuthentication: Secure login linked to the treasurer profile; enforced 8-12 character strong passwords and email-based 2FA.  Dashboard:Real-time welfare analytics (total collected this month/year, pending members, completed accounts).  Search members by phone number or ID with integrated photo thumbnails for visual identification.  Transaction Recording:Manual recording via Cash, Mobile Money, Bank Transfer, or Card (no payment gateway integration required).  Backend validation checks to prevent duplicate payments for the same billing cycle.Automatic generation of cryptographically secure receipts for both parties, instantly viewable in the member dashboard.  Settings Control:Update annual and monthly welfare contribution targets.  When a member hits the annual target, the system locks further payments for that year automatically unless settings change.  Data Management: Export complete transaction logs to CSV or PDF.  Profile Management: Update email and password (8-12 strong characters) with 2FA toggles. Password recovery via profile-triggered email reset links.  B. Members ModuleRegistration Form:Captures full name, date of birth, gender, email (mandatory for resets), phone number with country code selection, residential address, and optional occupation/student status.  Emergency contact details (name, relationship, phone).  Passport photo upload and 8-12 character strong password creation with confirmation fields and mandatory user consent check.  Automatic generation of a unique system ID (GYF-XXXXXX).  Authentication: Login utilizing the assigned Member ID and secure password.  Dashboard:Navigation bar featuring a small rounded profile thumbnail on the left, visible Member ID, and current status.  Archive of downloadable/viewable welfare transaction receipts.  Data Management: Export personal transaction history to CSV or PDF.  Settings & Security: Change password with confirmation and manage 2FA settings.  Password Reset: Use the unique Member ID to look up the registered email and receive a secure recovery link.  4. Security Framework (Anti-Hacking & Validation)SQL Injection Mitigation: Strictly utilize PHP PDO prepared statements with bound parameters for all database queries.XSS Defense: Sanitize all incoming global inputs and apply context-aware output escaping via htmlspecialchars() across all views.Password Security: Mandatory enforcement of 8-12 character complexity rules backed by PHP's native password_hash() (Bcrypt/Argon2).Duplication Protections:Database-level UNIQUE constraints implemented on member_id, email, and receipt numbers.Composite application-level unique checks for member billing cycles to completely block duplicate transaction logging.UI/UX Framework Choice: Bootstrap 5 will be integrated locally to guarantee a clean, secure, mobile-responsive interface utilizing standard light white, light blue, and light yellow design styling. Inline CSS will be strictly avoided.  5. Network & PWA Deployment RulesOnline-Only Enforcement: The system requires an active connection (navigator.onLine verification) to process records, preventing offline desynchronization issues.  PWA Configuration: Includes a Web App Manifest and Service Worker so members can seamlessly add the shortcut to their mobile home screens.  Android Packaging: Wrapped via Capacitor inside Android Studio to generate the native installation file specifically for the treasurer's Android device.
